# Study Buddy - AI Study Notes & Quiz Generator

Paste your notes, get AI-generated summarized study notes and an interactive quiz to test yourself.

## Tech Stack
- Frontend: HTML, CSS, JavaScript (vanilla)
- Backend: Node.js, Express
- AI: Claude API (Anthropic)

## Status
🚧 In progress — Phase 1: Static frontend

## Setup
1. Clone repo
2. `cd server && npm install`
3. Add your Anthropic API key to `server/.env` as `ANTHROPIC_API_KEY=your_key_here`
4. `node server/index.js`
5. Open `index.html` in browser (or use Live Server)
